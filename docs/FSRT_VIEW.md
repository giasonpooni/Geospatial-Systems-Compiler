# Inspect retained fluid snapshots

The existing `/numerics` local-file page now also accepts NET's additive
`ciw.fsrt-view-envelope.v1`. It retains the old mean-only and covariance readers
and UI. Use `python -m ciw.fsrt_view` in the companion Terminal to export an
explicit execution and record the reported payload digest independently.
Select the resulting JSON and its trusted expected digest. The file is read
inside the browser; no provider, upload, admission or control endpoint is called.

`src/lib/notation/fsrt-view.ts` checks the exact Python UTF-8 payload bytes,
record identities, supported snapshot shape, source/time/unit bindings, stage
ordering and status consistency. It rejects duplicate JSON keys, unsafe integer
representation, nonfinite numbers, excess nesting/bytes, unsupported claims and
inconsistent held/refused results. Captured bytes and recursively frozen results
prevent mutation races. It does not independently recompute the Gaussian update,
PSD eligibility, balance residual, covariance digest or statistical threshold.
The expected external digest binds those original records and Python float
spellings; copying a digest from the same untrusted file is not authentication.

The page separates calibrated observations, unprojected estimates and final
outputs. A held correction displays absent after-residual/correction values as
absent, not zeros. All six v2 covariance stages keep their full matrices and
identities, even when posterior and reconciled numbers coincide. V1 remains a
three-matrix legacy presentation, without invented v2 artifact IDs. A refusal
shows its original code/message and produces no empty or zero-valued estimate.
Original source, execution, model, covariance and assumption records are
inspectable as text. No confidence region, fault identification, location or
continuous flow field is inferred.

This is one simultaneous two-reservoir mass snapshot, not temporal fusion or a
general fluid simulation. Existing NET input assembly remains unchanged: complete
independent calibrated channels; full output correlations are retained. Supported
standalone FSRT inputs do not automatically become NET integration capabilities.
Export does not authorize publication. The full workspace remains the audit
artifact; this projection does not authenticate calibration or private metadata.

```sh
npm run build
npx playwright install chromium
FSRT_VIEW_FIXTURES=/path/to/verified/retained-bundle node validation/fsrt-browser.mjs
node validation/numerics-browser.mjs
```

The fixture index binds exact workspace/view files and payload digests. Real
fixtures are generated by the approved RCI/FSRT providers on public synthetic
inputs inside the private calibration owner's qualification workflow. They are
not domain doubles; their inputs are synthetic, not field evidence. Mutated
reader cases deliberately test malformed records. Missing fixtures fail the
reader/browser qualification rather than becoming a pass. `--compile-only` is
explicitly weaker and not a pipeline qualification.

The companion NET PR #42 uses its existing workspace reader without launching
providers. Private RCI PR #2 owns real end-to-end qualification, avoiding private
provider sources or credentials on public PR runners. This branch stacks on the
existing numerical viewer PR #7; it adds neither a second controller nor a live
artifact service. No prior branch, scientific kernel, runtime pin, licence,
source attribution, default branch or deployment is changed.
