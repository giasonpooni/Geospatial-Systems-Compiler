# Inspect synthetic-source FSRT results

The existing `/numerics` page now recognizes the additive
`ciw.simulated-fsrt-view-envelope.v1` without relabelling it as the old RCI-backed
view. Use NET's `python -m ciw.simulated_fsrt_view` on the compatible
`feat/synthetic-fsrt-gsc-v1` integration branch, select one retained estimator
execution and supply the independently recorded workspace digest. The exporter
prints `view_sha256`; use that exact payload digest in the browser, not a hash
of the enclosing JSON file. No file is uploaded.

The new header explicitly identifies a simulated observation, not physical
measurement or calibration. It shows the original simulation tick/rate/phase,
engine and estimator occurrence IDs, state/clock owner declarations, and entity
and sensor ordering. A one-second local workspace selection interval is not
elapsed simulation time. All six covariance stages, full cross terms, missing
observations, held correction and refused results keep their original meanings.
The separate simulator reference-state artifact is not included.

Source class and parsing remain separate from the existing RCI reader. Only
structural FSRT data checks and numerical presentation panels are shared. The
old reader keeps its original zero-time input profile and schema. Its native,
RCI-backed and legacy v1 views remain supported. No generic fluid-field, 3D
location, live stream, shared intent bus or new control plane is introduced.

## Integrity, not new scientific authority

The inspector hashes the exact outer payload and original simulated-observation
UTF-8 bytes, rejects duplicate keys, checks supported source/model/record/time/
entity/covariance bindings, rejects source/verification/physical-calibration
claims outside the contract, and returns deeply frozen records. The source and
estimator identities cannot be the same occurrence. Captured inputs and page
selection generations fence asynchronous file/digest changes.

The expected digest comes from the operator's trusted artifact selection.
Rewriting every payload/hash remains possible to a publisher: self-consistency
is not authentication. The browser does not recompute native record or covariance
digests, the estimator, statistical thresholds or a reference trajectory. It
performs representation checks only. The native `calibrated_observation` label
is accompanied by the explicit notice that these readings are simulated and
not physically measured or calibrated. Export is not publication, evidence
admission or equipment authorization.

## Run the checks

```sh
node scripts/check-simulated-fsrt-view.mjs --compile-only
SIMULATED_FSRT_VIEW_FIXTURES=/path/to/synthetic-views node scripts/check-simulated-fsrt-view.mjs
FSRT_VIEW_FIXTURES=/path/to/legacy-views node scripts/check-fsrt-view.mjs
npm run build
npx playwright install chromium
SIMULATED_FSRT_VIEW_FIXTURES=/path/to/synthetic-views \
  FSRT_VIEW_FIXTURES=/path/to/legacy-views node validation/simulated-fsrt-browser.mjs
```

The new tests require exact real exported observations generated by the existing
Godot/FSRT fixture; altered records are refusal challenges, not domain-model
alternatives. The browser checks ordinary, held, missing, both-missing and
singular-input outcomes, original time, all covariance stages, stale source/
digest races, 700px document scrolling, and switching between old/new sources.
Missing dependencies must fail qualification, not count as a passing mock.
The public compile-only workflow is explicitly not an end-to-end claim.

Complete combined qualification runs with the corresponding NET integration
revision and both source classes. Private RCI stays in its own repository's
read-only CI, without new credentials or source publication. Existing numerical
and browser regressions remain required. Prior campaign successes qualify their
recorded revisions; new success must be attached to the combined source state.
