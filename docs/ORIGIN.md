# Origin and retained notices

Payload Terminal's repository began from `simplifaisoul/osiris`, an MIT-licensed
situational-awareness dashboard. Inherited map/interface code remains in the
legacy application. Subsequent Notation Systems development includes evidence
records, commodity and freight workflows, and the visualization-first explorer.

The README leads with current capabilities rather than this history. That is
an editorial change, not a claim of independent origin, a completed source
rewrite, or a license change. The [replacement ledger](REPLACEMENT_LEDGER.md)
tracks responsibility-level changes without erasing historical provenance.

The original [MIT notice](licenses/osiris-MIT.txt) is retained verbatim from
https://github.com/simplifaisoul/osiris/blob/master/LICENSE, blob
`4f9328b44947cb3b8c4b7c6963772b6aaf26db73`. Keep applicable notices with retained
code and distributed substantial portions. Dependency notices remain applicable
as well. The project-wide [GNU GPL v3.0 license](../LICENSE) is unchanged.

Removing or replacing a capability is not evidence that every inherited source
portion has been removed. Any future notice-scope change requires an actual
source and distribution review; this increment makes no such change.
